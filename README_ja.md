# 🤖 デスクトップペット

**デスクトップに住みつく、ちっちゃなインタラクティブ・ドット絵ロボット。**

ウィンドウの上にちょこんといます。お腹が空きます。寝落ちします。勝手にうろうろします。たまにピクセルな目であなたを見つめ返します。

---

## これなに

- 透明な常時最前面ウィンドウで画面に居座ります——タイトルバーも枠もなし、ただロボットがいるだけ
- 空腹・体力・幸福度がリアルタイムで減っていく、ちょっとした育成要素
- 暇になると勝手に歩き出す（待機 → 歩行の自動遷移）
- 通知もうるさいポップアップも一切なし——でもクリックするとキラキラ喜ぶ

## 機能

- **5 種のドットアニメーション** — 待機（まばたき）、歩行、睡眠（ZZZ）、食事、喜び（キラキラ目）
- **有限状態マシン** — きれいに整理された状態遷移ロジック
- **システムトレイ常駐** — 邪魔なときはトレイにしまっておける
- **属性システム** — 満腹度 / 幸福度 / 体力の減衰、コインの受動獲得
- **ショップ** — コインで食べ物を買って属性を回復
- **オフライン補正** — 5分ごとにオートセーブ、再起動時に不在時間を計算して減衰
- **クリック反応** — シングルクリックで +5 幸福度、ダブルで +10
- **ドラッグ移動** — つかんで好きなところへ
- **ピクセル単位のマスク** — 空白部分はクリックが素通り、作業の邪魔をしない

## クイックスタート

```bash
git clone git@github.com:jiangziyong3-lgtm/desktop-pet.git
cd desktop-pet

python -m venv venv
source venv/bin/activate   # Windows は `venv\Scripts\activate`

pip install -r requirements.txt
python main.py
```

**要件:** Python 3.9+, PySide6 ≥ 6.5.0

## プロジェクト構成

```
main.py              → エントリポイント
pet_window.py        → 透明ウィンドウ、ドラッグ、コンテキストメニュー、ステータスパネル
state_machine.py     → 有限状態マシン
animator.py          → フレーム再生（ループ / 単発）
renderer.py          → ピクセル描画（左右反転つき）
sprites.py           → 16×16 スプライトデータ（パレットインデックス）
attributes.py        → 属性減衰、コイン収入、危険閾値
save_manager.py      → JSON セーブ + オフライン補正
tray.py              → システムトレイアイコン & メニュー
config.py            → 各種パラメータ（ピクセルサイズ、減衰率、パレット…）
states/              → 状態ごとの振る舞い（idle, walk, sleep, eat, happy, drag）
shop/                → ショップ UI & アイテム定義
```
